# Global Layoffs Data Cleaning & Exploratory Data Analysis (SQL)

## Project Overview

This project focuses on cleaning and analyzing a real-world layoffs dataset using MySQL.

The objective was to transform raw data into a clean and reliable dataset before performing exploratory data analysis to identify trends and patterns in workforce reductions across industries, companies, and countries.

## Tools Used

- MySQL
- SQL

## Data Cleaning Tasks

- Removed duplicate records
- Standardized inconsistent values
- Handled missing and null values
- Improved overall data quality

## Exploratory Data Analysis

The analysis explored:

- Layoffs by company
- Layoffs by industry
- Layoffs by country
- Year-wise layoff trends
- Monthly layoff patterns
- Companies with the highest layoffs

## SQL Concepts Used

- CTEs
- Window Functions
- Joins
- GROUP BY
- Aggregate Functions
- Subqueries
